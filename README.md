# 心智五力鍛鍊測驗站（原型版）

給學生線上作答的靜態網站，無後端、無登入、匿名作答。

## 開啟方式（擇一）
- 本機展示：用瀏覽器直接開啟 `index.html`。
- 教室／線上作答：把整個 `site/` 資料夾放到學校網頁空間、GitHub Pages、Cloudflare Pages 等靜態託管即可（index.html 為進入點）。

## 五個分頁對應提示詞
1. 五力測驗：30 題虛構情境（每力 6 題，選項藏分 3/2/1/0，順序已打散）。
2. 雷達圖結果：canvas 繪製、每力 __/18 分＋狀態（≥14 高度發展／10–13 良好發展／≤9 持續培養）、JSON 下載、列印存 PDF、匿名代碼。
3. 21 天計畫：年級／性別／興趣／專長＋選一力加強，產出三週計畫。
4. 學習資源：每力自學摘要＋7 選 2 每日小任務＋YouTube 搜尋連結。
5. AI 小精靈：規則式 SEL 引導（原型，非大型 AI）。

## 老師專區（分頁②底部）
- 結果只存在「作答裝置」的瀏覽器 localStorage，本機可看表、匯出 CSV、清空。
- 班級彙整：請學生繳交「匿名代碼＋各力分數」或 CSV，不要蒐集姓名。
- 沒有後端伺服器，就沒有「後台即時看全班」；若學校之後要此功能，需另建後端＋個資同意流程。

## 隱私與課堂提醒
- 題庫與範例全為虛構，不含真實學生資料。
- 請勿要求學生填寫姓名、學號；代碼範例：WULI-XXXX。
- Google 雲端備份採「學生自行下載 JSON 後上傳」，本站不碰帳號。
